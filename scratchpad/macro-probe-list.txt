# The per-macro probe set for gcc.target/multi-target/macro-probe.exp.
#
# WHERE THIS LIST COMES FROM, and what it is NOT.
#
# 143 macros are defined with DIFFERING TEXT by the i386 and aarch64 bases and
# are spelled by target-independent code.  From those, five groups are removed
# and the removals are listed here rather than left implicit:
#
#   12 driver-only spec strings (ASM_SPEC CC1_SPEC CPP_SPEC DRIVER_SELF_SPECS
#      ENDFILE_SPEC LIB_SPEC LINK_SPEC STARTFILE_SPEC MULTILIB_DEFAULTS
#      OPTION_DEFAULT_SPECS EXTRA_SPECS EXTRA_SPEC_FUNCTIONS) -- referenced
#      only from gcc.cc and friends, never from cc1, and already owned by this
#      branch target-specs mechanism.
#    1 TYPE_OPERAND_FMT -- appears in no .cc at all.
#    2 targetm hook initialisers (TARGET_ASM_FILE_END TARGET_ASM_SELECT_SECTION)
#      -- already solved at run time by f82b65386d0.  A header probe cannot see
#      a runtime pointer, so scoring them here would be a false red.
#
# leaving 128, of which exactly ONE (MAX_BITS_PER_WORD) is expected to pass for
# both bases: its text differs and its value does not (64 = 64).  It is kept in
# the set deliberately, as the one probe that proves a PASS is possible.
# 127 actionable.
#
# Then 10 more are ADDED that no text diff can find, because their definition
# text is byte-identical on both bases:
#   N_REG_CLASSES        34 vs 20 -- the macro behind the aarch64.cc:14322 ICE
#   BITS_PER_WORD        runtime (TARGET_64BIT) on i386, constant 64 on aarch64
#   and 8 more asymmetric constant/runtime pairs.
#
# TOTAL 138.  THIS IS A LOWER BOUND, NOT A CEILING.  ~1049 identical-text
# non-integer macros have never been classified; the honest statement about the
# population is ">= 137 actionable, no established upper bound".
#
# Columns: NAME  CLASS   (class per MACRO-LEAK.md; informational, not used for
# scoring -- the harness picks its probe shape by measurement, not by this)
