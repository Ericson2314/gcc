## 2. A silent C++ ABI break on five back ends, measured

`cp/cp-tree.h:24` is one of the four shared headers that carry `tm.h`, and
**39 of 42 `cp/*.o` open it** (read from `cp/.deps/*.Po`, which names
`config/i386/i386.h`, `biarch64.h`, `linux64.h`, ... -- i386's whole chain).
So every `tm.h` macro `cp/` spells is answered by the primary for all 47 back
ends.  The ranked surface, by definer count under `config/`:

| macro | uses in `cp/` | definers | shape |
|---|---|---|---|
| `TARGET_PTRMEMFUNC_VBIT_LOCATION` | 5 | 6 | **primary's answer leaks** |
| `TARGET_VTABLE_USES_DESCRIPTORS` | 16 | 1 (ia64) | **leaked absence** |
| `TARGET_VTABLE_DATA_ENTRY_DISTANCE` | 11 | 1 (ia64) | leaked absence |
| `TARGET_VTABLE_ENTRY_ALIGN` | 1 | 3 (ia64 avr msp430) | leaked absence |
| `POINTER_SIZE` | 2 | 27 | |
| `MAX_FIXED_MODE_SIZE` | 2 | 23 | |
| `MALLOC_ABI_ALIGNMENT` | 2 | 7 | |

`agent-a260445cf27ba480a-cxxmacros.sh`, with both controls.

**`TARGET_PTRMEMFUNC_VBIT_LOCATION` is the live one, and it is the
`REGMODE_NATURAL_SIZE`/`EPILOGUE_USES` trap in a new place.**

```
i386/i386.h:832       ptrmemfunc_vbit_in_pfn
aarch64/aarch64.h:125 ptrmemfunc_vbit_in_delta
arm/arm.h:675         ptrmemfunc_vbit_in_delta
mips/mips.h:2441      ptrmemfunc_vbit_in_delta
loongarch/loongarch.h:637  ptrmemfunc_vbit_in_delta
arc/arc.h:1541        (conditional)
defaults.h:1023       #ifndef -- DEAD, i386 defines the name first
```

Measured with the built `cc1plus`, both-sided, on
`agent-a260445cf27ba480a-ptrmem.cc` at `-O2`
(`agent-a260445cf27ba480a-ptrmem.sh`):

```
                     x86_64                    aarch64
mt_pmf_first    .quad 1  / .quad 0         .xword 1  / .xword 0
mt_pmf_second   .quad 9  / .quad 0         .xword 9  / .xword 0
mt_pmf_nonvirtual .quad _ZN1D1hEv / 0      .xword _ZN1D1hEv / 0   <- CONTROL
```

x86_64 is **correct** (`vbit_in_pfn`: pfn odd, delta 0).  aarch64 emits **the
identical layout**, and its own header asks for `vbit_in_delta` -- pfn 0/8 with
delta 1.  The non-virtual control is identical on both sides, as it must be
under either convention, so the comparison is measuring the vbit and nothing
else.

A pointer to a member function is an ABI-visible object.  `cc1plus` here emits,
for aarch64 arm mips loongarch and arc, a representation no correct C++
compiler for those targets can interoperate with -- with rc=0, no diagnostic,
and assembly a real cross assembler accepts.  It is the `EPILOGUE_USES` shape:
nothing in this project's instrument set was looking for it, because no
instrument compiled C++.

**A written claim in the tree measures FALSE because of this, and it is worth
recording.**  `target-cdata.h`'s `FUNCTION_BOUNDARY` comment says the
`FUNCTION_BOUNDARY` leak is "also read by `defaults.h:1024`
(TARGET_PTRMEMFUNC_VBIT_LOCATION) ... so the leak reaches the ABI of pointers
to member functions".  The reasoning is right about the fallback and the
fallback is **never taken**: `i386.h:832` defines the name before `defaults.h`
is reached.  Converting `FUNCTION_BOUNDARY` therefore does nothing for pointers
to member functions, and the sentence reads as though the question had been
asked.  Same family as the `sweep.sh` citation.

**The fix is the settled one** -- a `NUM` entry in `TARGET_CDATA_FIELDS`
alongside `bytes_big_endian` and `function_boundary` -- and it is NOT done
here: it touches a per-base table and ~40 shared C++ objects, so it needs its
own 47-base build to validate, and the C++ score run had not finished.

## 3. What was NOT measured

* No language other than C and C++ was built.  `cc1d`, `cc1rust`, `f951`,
  `libgccjit` were not compiled, not linked and not run; see
  `A260445CF27BA480A-LANGLISTS.md` for what is wrong with them on paper.
* `objc` / `obj-c++` were not enabled.  They need no separate fix -- they reach
  `C_TARGET_OBJS` / `CXX_TARGET_OBJS` through `C_AND_OBJC_OBJS` /
  `CXX_AND_OBJCXX_OBJS` -- but that is read, not run.
* The `TARGET_VTABLE_*` entries above are a source census.  ia64 was not
  compiled with a C++ testcase, so "ia64 gets 0 descriptors" is inferred from
  the dead-`#ifndef` argument, not observed.
