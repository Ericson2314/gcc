# STATUS OF EVERY PROBED MACRO.  The score is over STATUSES, never over the
# arms that happen to survive.
#
#   UNCONVERTED        scored by macro-probe.sh (INT/STR/EXP).  Absence of the
#                      macro from both bases scores FAIL, not "absent".
#   CONVERTED_SUPPLY   routed through a targetm hook, but the back end still
#                      spells the macro -- that IS how it supplies the hook.
#                      Keeps its header arm AND gains a TAB arm; both scored.
#   CONVERTED_CDATA    a (c-DATA) macro: the NAME survives and is still spelled
#                      everywhere, but defaults.h redirects it to a per-config
#                      slot, so in BOTH bases' header contexts it now expands to
#                      the same target-neutral text.  The header arm therefore
#                      stops measuring the macro's VALUE and starts reporting
#                      agreement about the redirect -- which flipped four
#                      aarch64 arms FAIL -> PASS for entirely the wrong reason
#                      on the first Stage 2 run.  So the header arm is RETIRED
#                      and the TAB arm is mandatory, by the same mechanical
#                      check as CONVERTED_GONE.  This status exists because the
#                      original two covered arms that DISAPPEAR and not arms
#                      that turn green.
#   CONVERTED_REGS     the register-vocabulary form of CONVERTED_CDATA, and it
#                      exists for the same reason: three aarch64 arms flipped
#                      FAIL -> PASS when ecad6abf6ae landed, and every one of
#                      those passes said only "both header contexts now agree
#                      that this name is target-neutral".
#                        FIRST_PSEUDO_REGISTER and N_REG_CLASSES became the
#                      compile-time UNION width, which is DELIBERATELY the same
#                      number in every consumer translation unit -- it is the
#                      layout of target_hard_regs/target_regs/target_ira/
#                      target_ira_int.  REGNO_REG_CLASS became a call through
#                      targetm_regs.  In all three cases the per-base fact moved
#                      to a RUN-TIME datum, so the header probe cannot see it
#                      any more and its agreement is not evidence of anything.
#                      Header arm RETIRED, TAB arm mandatory, by the same
#                      mechanical check as CONVERTED_GONE.
#                        The status is separate from CONVERTED_CDATA because the
#                      two are checked differently: CONVERTED_CDATA's redirect
#                      is `#define M (targetm_cdata.', this one's is a read of
#                      MULTI_TARGET_UNION_* or of targetm_regs.  One status
#                      covering both would need a completeness check that
#                      accepted either, i.e. one that is satisfied by the wrong
#                      redirect.
#   CONVERTED_GONE     routed through a hook and the macro is deleted from the
#                      back ends.  The header arm is retired and a TAB arm
#                      MUST exist in tab-probe.sh, or macro-probe.sh aborts.
#   CONVERTED_EXIST    covered by the FIFTH probe shape, `exist-probe.sh',
#                      which reads the two per-base OBJECTS side by side with
#                      NEITHER base selected.  The macro MUST appear in
#                      exist-probe.sh's EXIST_MACROS line -- a name in
#                      tab-probe.sh's TAB_MACROS does NOT satisfy this, and
#                      vice versa, because the two shapes measure different
#                      propositions.  Header arm RETIRED, for the usual reason:
#                      these are all `defaults.h' redirects, so in the probe's
#                      base-B context (which does not define
#                      MULTI_TARGET_TARGETM_BASE) BOTH sides expand to the same
#                      `mt_*' call and the arm compares a redirect with itself.
#                        AN EXIST ARM IS NOT A VALUE ARM AND MUST NEVER BE
#                      TOTALLED WITH ONE.  exist-probe.sh scores two separate
#                      properties: VALUE, only when both bases' thunks compiled
#                      to a constant return and only against a PRE-REGISTERED
#                      table; and DISTINCTNESS, which is scoreable for all of
#                      them.  Six of the nine are UNMEASURABLE-BY-THIS-ARM for
#                      value -- their thunks read option state -- and that is
#                      recorded as a verdict, not smoothed into a pass.  The
#                      status says "this macro has an arm that can fail"; it
#                      does not say "this macro's value has been verified".
#   CONVERTED_UNION    converted by the genmodes UNION: the macro is a
#                      compile-time WIDTH that must be identical in every
#                      translation unit, and the shared answer is the MAXIMUM
#                      over the configured back ends.  Covered by the SIXTH
#                      shape, `union-probe.sh'; the macro MUST appear in its
#                      UNION_MACROS line, and a name in TAB_MACROS or
#                      EXIST_MACROS does NOT satisfy it.
#                        THIS STATUS EXISTS BECAUSE EVERY OTHER ARM ON THE
#                      BOARD IS GREEN FOR A UNION MACRO BY CONSTRUCTION.  The
#                      number is DELIBERATELY the same in both bases -- that is
#                      the fix, not a symptom -- so the header arm's PASS says
#                      only "this name is target-neutral", and a TAB arm
#                      reading the running cc1 would say the same thing again.
#                      Header arm RETIRED.
#                        What `union-probe.sh' scores instead is the
#                      proposition that is actually true of a union macro, in
#                      three parts: NON-VACUITY (at least two bases must
#                      disagree on their own, else the union does nothing),
#                      MAXIMUM (the shared answer is the max, and in particular
#                      is NOT the primary's own answer), and BOTH-SIDEDNESS
#                      (the per-base generators are read separately, so the arm
#                      can tell "the union works" from "everyone now gets
#                      aarch64's answer").
#   CONVERTED_NOARM    CONVERTED IN THE COMPILER AND NOT MEASURED BY ANYTHING.
#                      This status exists because the alternative shapes are
#                      both lies:
#                        * marking it UNCONVERTED says the conversion has not
#                          happened, which sent at least two agents to convert
#                          a macro that was already converted; and
#                        * marking it CONVERTED_* claims an arm, which is
#                          banking a pass that nobody measured.
#                      It is the MEASUREMENT DEBT, on the board, countable, in
#                      its own column.  It retires NOTHING: a CONVERTED_NOARM
#                      macro keeps whatever header arm it had, because retiring
#                      an arm without supplying a replacement is exactly the
#                      disappearance the anti-floor gate exists to prevent --
#                      even though that header arm is, for a redirected macro,
#                      a redirect-vs-itself comparison and must not be read as
#                      evidence.  It is kept so the number does not silently
#                      shrink, not because it means anything.
#                      A CONVERTED_NOARM entry is a TODO with a name.
#
# A macro may move UNCONVERTED -> CONVERTED_{SUPPLY,CDATA,REGS,GONE} only in the
# same change that adds its TAB arm, and -> CONVERTED_EXIST only in the same
# change that adds its EXIST arm.  macro-probe.sh enforces both mechanically
# against tab-probe.sh's TAB_MACROS and exist-probe.sh's EXIST_MACROS; it is
# not an invariant anyone has to remember.
#
